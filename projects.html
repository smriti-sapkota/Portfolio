WebGuard — Web Vulnerability Scanner

A web vulnerability scanner built by our 7th semester team. I wrote the FastAPI backend that does the scanning; my teammates built the React interface.

  • Multi-threaded crawler that maps up to 50 pages per scan.
  • Tests for reflected XSS, SQL injection and CSRF, plus missing security headers.
  • PostgreSQL storage, Docker Compose and Azure deployment.
