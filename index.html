webguard

AcademicTeam project7th semester

WebGuard

A web vulnerability scanner built as a team project for my seventh semester. I wrote the FastAPI backend that does the scanning:

  • A multi-threaded crawler that maps up to 50 same-domain pages per scan.
  • Reflected XSS and SQL injection tests on forms and URL parameters, using error-based, boolean-blind and time-based checks.
  • CSRF checks for missing form tokens and cookies without SameSite, plus missing X-Frame-Options and CSP headers.
  • Optional logged-in scans, readable network-error messages, PostgreSQL storage with SQLModel and Alembic, Docker Compose, and an Azure App Service deploy workflow.

My teammates built the React interface.
