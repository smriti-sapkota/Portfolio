PrimeGold CRM

InternshipMulti-tenant platformNext.js · Django

A multi-tenant gold-shop management platform. I built customer-facing workflows and admin tools across a Next.js, React and TypeScript frontend, with selected Django backend and API changes.

primegold-crm

What I did

  • Sales & customers: Added customer selection and management, and contributed to the sales and order process: choosing products, creating orders, invoices, payment and history views.
  • Jewellery inventory: Created a guided “Easy Mode” for adding jewellery, with draft support to make product entry simpler.
  • Purchasing & suppliers: Added supplier and bank support to purchase forms, seller and bank selection, purchase history, invoice downloads and debit-note workflows.
  • Goldsmith jobs: Improved sales-order selection with search and state handling for goldsmith jobs.
  • Finance pages: Added search and filtering to withdrawals and opening-balance records.
  • Staff & platform admin: Built staff profiles, role filtering, permissions and password-management screens, plus a redesigned superuser login and a responsive admin console.
  • Shared foundations: Worked on API and session handling, stock-alert data fetching, contact-image uploads, error recovery, and refactoring shared UI and page code.
