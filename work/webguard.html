WebGuard — Web Vulnerability Scanner

AcademicTeam project7th semester

A web vulnerability scanner built as a team project for my BSc CSIT final year. I wrote the FastAPI backend that performs the scanning; teammates built the React interface.

webguard

What I did

  • Multi-threaded crawler mapping up to 50 same-domain pages per scan.
  • Reflected XSS and SQL injection tests on forms and URL parameters.
  • CSRF checks, missing X-Frame-Options and CSP header detection.
  • PostgreSQL storage with SQLModel, Docker Compose, and Azure App Service deployment.
  • Python
  • FastAPI
  • SQLModel
  • PostgreSQL
